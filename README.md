# Flight Sim Template

A website template for flight simulator centres, designed and built by BloxForLife.

Plain HTML, CSS and JavaScript, no framework. It includes:

- Home page with an animated hero, stats counter and explore cards
- Sessions and pricing, with a Book button on every session
- Booking page: pick a session, date and time, then call to confirm
- Photo gallery with a masonry layout and a lightbox
- Reviews, FAQ and contact pages, with a map
- Mobile menu, scroll reveals and a custom 404 page

Names, prices, contact details and reviews are placeholders, ready to be replaced with a real business's details. Gallery photos are from Wikimedia Commons and are credited on the gallery page.

## Build

`npm run build` copies the site into `dist/`, which is what Vercel serves.
